## Requirements

### Functional
1. The user needs an interface to deliver the pdf of the paper.

2. The system needs to strip out the text structure of the paper, aswell the images and tables.

3. The system needs to create a folder with the name of the papers pdf inside the output folder.

4. The system needs to create one note per section of the paper (one for the introduction, another for methodology, etc.)

5. The system needs to reassure the paragraphs structure and placement of tables and images are in a good level of organization. If the user needs to perform too much manual corrections, it becomes a liability

### Non-Functional
1. The user should spend at maximum 20 seconds performing this chain of processes: opening app -> choosing the file -> starting the file parsing.

2. The system should spend at maximum 120 seconds parsing the file and creating the notes inside Obsidian.
