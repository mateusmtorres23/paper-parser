# PaperParser

PaperParser is a tool for converting scientific papers from PDF into organized Markdown notes.

It extracts the paper's content and images, identifies its sections, and generates separate Markdown files that can be used directly inside an Obsidian Vault.

The goal is to make reading and annotating scientific papers a more pleasant experience.

## Status

PaperParser is currently under development.

## Planned Features

- Improved Markdown cleaning and organization
- Automated tests
